Côté DSI

Quatre étapes pour installer.

Une VM, le script livré avec la licence, puis la clé du fournisseur choisi. Docker doit déjà être là : le script ne l'installe pas.

01

Une VM Linux

Docker et Docker Compose sont installés avant le script. S'ils manquent, le script s'arrête.

02

Le script d'installation

Il charge l'image Docker fournie (fichier .tar) et démarre l'application avec Docker Compose. Le port par défaut est 3000, ensuite publié sur l'adresse interne.

03

Une clé API

Dans les réglages : Mistral, Claude, ou un autre fournisseur. Une clé pour la collectivité, pas une par agent. L'usage est facturé par ce fournisseur.

04

Ollama, si pas d'API externe

Une seconde VM peut porter les modèles locaux. Le script peut installer Ollama sous Linux et télécharger les modèles : comptez plusieurs minutes. Les questions restent sur cette VM.

Plafond journalier

  • Le quota du compte (Mistral, Claude ou un autre) est réparti automatiquement.
  • Un plafond journalier est calculé pour chaque agent.
  • Il suit le quota réel du compte, pour qu'un agent ne brûle pas le stock de tokens de la collectivité.

Pour les agents

Une adresse. Pas un logiciel sur chaque poste.

Ils ouvrent l'adresse interne, ou épinglent l'application depuis le navigateur. Les conversations restent dans le volume Docker de la DSI.

Secrétariat

Arrêtés, délibérations, courrier au préfet, ordre du jour du conseil.

RH

Statut, recrutement de contractuels, RIFSEEP, congés, fiches de poste.

Urbanisme

PLU, délais d'instruction, seuils, MAPA, notes pour le DGS.

Finances

DGF, FCTVA, DETR, DSIL, lecture d'une commune de la même strate.

Où vont les données

Le dossier reste à la mairie.

STELLARMEET n'héberge pas les conversations. Le texte d'une question part vers le fournisseur choisi par la DSI, ou reste sur la VM Ollama si la collectivité est en mode local.

Le poste

L'agent pose sa question dans le navigateur, sur l'adresse interne.

Le serveur

Comptes, conversations et fichiers déposés restent dans le volume Docker de la DSI.

Le modèle

En mode API, le texte nécessaire à la réponse part vers le compte choisi par la DSI : Mistral, Claude ou un autre. La facture d'usage est celle de la collectivité. En mode Ollama, ce texte reste sur la VM locale.

Le détail est dans la politique de confidentialité et le DPA.
