Le volume des contenus a un nom, et la sauvegarde le vise

12 novembre 2026 · TerritoIA, édité par STELLARMEET

L’application tient dans une image. Les contenus tiennent dans un volume. Confondre les deux, c’est croire qu’une mise à jour ou une copie de l’image emporte les dossiers. Ce n’est pas le cas. La DSI écrit le nom du volume dans la procédure, à côté du nom de la VM, et elle sauvegarde ce volume.

Vérifier une fois

Elle restaure un essai hors production, elle ouvre une pièce de test, elle détruit l’essai. Elle relit que l’essai n’est plus joignable. Les agents ne participent pas. Le maire ne signe pas la procédure de sauvegarde. Ce n’est pas un acte municipal. C’est un geste d’exploitation.

STELLARMEET ne conserve pas ce volume et n’en garde pas une copie de secours. Dire le contraire dans une note au DGS se corrige. La DSI relit les notes anciennes au moment de cette vérification, parce que les formules rassurantes s’y glissent.

Ce qu’on ne met pas dans le volume

Pas d’export du standard, pas de liste d’habitants, pas de dossier médical ou social nominatif « pour aider le CCAS à tester ». Le CCAS, s’il entre un jour, déposera des procédures sans noms. TerritoIA n’est pas un accueil des usagers. Le volume n’est pas un entrepôt de tout le système d’information.

Un agent ne copie pas le volume sur une clé pour travailler chez lui. La DSI le dit dans la consigne. L’adresse interne, via le réseau prévu, suffit. Le fil repris le lendemain est sur la VM, pas sur la clé.

Incident

Si le volume est plein ou illisible, la DSI traite l’incident technique avec le support, sans envoyer les pièces. Les agents travaillent sur leurs dossiers d’origine. Ils relisent ces dossiers. Rien ne se signe depuis une sauvegarde. Les habitants ne sont pas informés d’un incident qu’ils ne peuvent pas voir. Le site municipal ne mentionne pas le volume.

Le nom du volume se recopie dans le plan de reprise, pas seulement dans la procédure quotidienne. La personne d’astreinte le retrouve sans appeler le titulaire. La DSI relit le plan après l’avoir modifié, en cherchant l’ancien chemin. Un chemin mort se barre. Les agents ne connaissent pas ce nom et n’ont pas à le connaître. Ils connaissent l’adresse interne. Le jour où la sauvegarde sert vraiment, ils sauront seulement si l’adresse répond de nouveau. Le maire n’est pas dans la chaîne d’astreinte de ce volume. Les habitants ne sont pas destinataires d’un message de reprise.

Une fois l’an, la DSI relit le nom du volume à voix haute avec la personne d’astreinte, devant la procédure, pas devant les agents. Si le nom a dérivé, la procédure se corrige le jour même. On ne laisse pas deux noms « historiques ».

Le nom juste se retrouve aussi dans le rapport de sauvegarde du matin, pas seulement sur le papier. La DSI ouvre ce rapport une fois après avoir corrigé la procédure, pour voir le même nom.
