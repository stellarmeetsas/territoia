La paie se corrige dans le logiciel de paie, par le gestionnaire habilité

12 novembre 2026 · TerritoIA, édité par STELLARMEET

Non. Le logiciel de paie est le seul endroit où le bulletin se calcule et se modifie, avec les habilitations et la trace prévues. L’outil interne des agents ne voit pas les éléments de paie, et il ne doit pas les recevoir. Le gestionnaire peut demander, de façon abstraite, comment lire une rubrique de bulletin ou quel acte RH est nécessaire avant une modification. Il ne colle pas le bulletin. Il relit l’acte RH. C’est l’acte qui autorise la modification, pas une conversation.

Pièce avant modification

Changement de grade, temps partiel, prime, retenue : chacun s’appuie sur un arrêté ou une délibération que le gestionnaire a dans le dossier. Sans pièce, il ne saisit pas « en attendant le papier ». Le RH fournit la pièce. Le gestionnaire vérifie la date d’effet et l’applique dans le logiciel de paie.

On peut aider le RH à vérifier qu’un projet d’arrêté contient les mentions utiles à la paie : identité déjà connue du dossier, date, élément modifié, sans redemander ces données dans l’outil général. Le RH relit ces mentions sur l’arrêté, pas dans un résumé.

Erreur de bulletin

Si un agent signale une erreur, le gestionnaire la vérifie dans le logiciel et dans l’acte. Il ne demande pas à un assistant « quel est le bon montant ». Le bon montant est celui que l’acte et le barème officiel donnent, lus par le gestionnaire. La correction suit le circuit de paie, y compris le rappel ou la retenue si elle est fondée.

Il relit le bulletin suivant. L’agent reçoit le bulletin par le canal habituel. L’outil général n’est pas ce canal.

Public

Les usagers n’ont aucun accès aux bulletins. Les autres agents non plus. L’outil interne n’est pas un accueil RH ouvert et pas le site municipal. Le maire ne signe pas les bulletins un par un : il a signé les actes qui les fondent, et l’ordonnateur suit le circuit financier de la paie.

Le gestionnaire archive le ticket de correction avec l’acte. Il relit que le nom sur le ticket est celui du bulletin modifié. Une correction sur le mauvais dossier est l’incident que cette relecture évite.

Demande d’explication

L’agent qui ne comprend pas une ligne obtient une explication du gestionnaire, à partir du bulletin et de l’acte, oralement ou par le canal RH. Le gestionnaire ne colle pas le bulletin dans l’outil pour préparer l’explication. Il peut vérifier dans le texte, de façon générale, ce qu’une rubrique signifie, puis il revient au dossier.

Il relit ce qu’il s’apprête à dire : pas de montant d’un autre agent, pas de promesse de régularisation non décidée. L’autorité signe s’il faut un nouvel acte. L’outil ne signe rien.

Le gestionnaire note le numéro de l’acte RH dans le commentaire de paie prévu par le logiciel, pas dans une conversation. Il relit ce numéro. L’agent voit le bulletin corrigé. L’outil général n’est pas un accueil RH. Le maire a signé l’acte qui fonde la correction.
