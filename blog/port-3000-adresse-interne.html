Installation par la DSI

Le port 3000 de TerritoIA reste une adresse interne

12 novembre 2026 · TerritoIA, édité par STELLARMEET

Après installation, l’application répond sur le port 3000 de la machine. La DSI donne aux agents une adresse interne, éventuellement derrière son propre proxy. Cette adresse ne figure pas sur le site de la commune.

Adresse que les agents retiennent

Un nom interne stable vaut mieux qu’une IP collée dans un courriel. La DSI le choisit, elle le fait résoudre sur le réseau de la collectivité, et elle le met dans les favoris ou l’intranet. Elle relit que ce nom ne sort pas sur Internet.

Ce que l’on n’ouvre pas

On n’ouvre pas le port vers le public, vers le wifi invité ni vers un formulaire habitants. TerritoIA n’est pas un accueil des usagers. Un test « depuis mon téléphone perso » qui réussit est un défaut de cloisonnement, pas une bonne nouvelle.

Signature

Le maire ne signe pas les textes préparés dans l’outil parce que le port répond. La réponse reste un brouillon relu. La DSI note dans le journal le nom interne et le port, sans y coller de capture de dossier.

Quand le certificat interne est posé, la DSI vérifie l’avertissement du navigateur depuis un poste agent, pas depuis une machine hors réseau. Elle relit que l’avertissement a disparu. Un contournement « cliquez quand même » ne s’écrit pas dans la consigne.

La DSI dessine le chemin réel : poste de l’agent, éventuellement proxy interne, VM, port 3000. Elle note ce chemin en trois lignes, pas en un schéma décoratif. Si un pare-feu intermédiaire existe, la règle est nominative et datée. Une règle « any » ouverte le temps d’une démo se ferme avant que les agents reçoivent le favori. Elle relit la règle le lendemain, pas seulement le soir même où tout le monde est pressé.

Le certificat, s’il est interne, est celui de la collectivité. On n’apprend pas aux agents à cliquer sur l’avertissement du navigateur. La DSI fait l’essai depuis un poste type, avec le compte d’un agent volontaire, puis elle retire ce qu’il a pu taper. Ce n’était pas un dossier. Les habitants ne font pas cet essai. Leur navigateur ne doit pas résoudre le nom.

Quand un élu demande l’adresse sur son téléphone personnel, la réponse est le réseau distant déjà cadré par la DSI, ou pas d’accès. On n’ouvre pas le port pour un appareil. TerritoIA n’est pas un accueil des usagers. Le maire ne signe pas depuis cette adresse. L’agent qui prépare un texte le relit dans le service, hors de l’écran s’il le faut, avant que le circuit de signature habituel s’en saisisse.

Le favori diffusé aux agents porte le nom, pas l’adresse IP et le port en clair. La DSI relit le favori sur un poste du secrétariat. Un favori bricolé vers l’IP se retire. Le port 3000 reste un détail d’exploitation, pas une consigne affichée.
