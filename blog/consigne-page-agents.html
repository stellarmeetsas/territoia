La consigne aux agents tient sur une page

12 novembre 2026 · TerritoIA, édité par STELLARMEET

Les agents ne liront pas la note d’architecture. Ils lisent une page. Elle dit où cliquer, quoi ne pas faire, qui prévenir. Elle se tient à jour. Une consigne longue est une consigne que personne ne relit, au sens propre : elle jaunit dans un partage.

Les cinq lignes

L’adresse interne. L’outil aide à retrouver une pièce et à préparer un texte. Vous ouvrez la pièce et vous relisez. Vous ne faites pas signer l’écran, le maire non plus. Vous ne déposez pas de dossier nominatif et vous ne tournez pas l’écran vers un habitant. Si l’adresse ne répond pas, vous appelez la personne nommée, vous n’ouvrez pas un compte ailleurs.

La DSI écrit ces lignes avec le service pilote, pas seule dans son vocabulaire. Elle relit avec un agent qui n’était pas dans le projet. S’il ne comprend pas une ligne, la ligne change. Les mots internes inutiles sautent.

Ce qui n’est pas sur la page

Le détail du volume, le port, le nom de l’image, le contrat du modèle : ailleurs, pour la DSI. Le prix, seulement si les agents ont à le connaître, ce qui est rare. S’il figure, il est exact : gratuit sous 3 500 utilisateurs, puis 7 000 € HT par an, quelle que soit la taille. Pas de TTC. Pas de durée inventée.

Pas de rang, pas de promesse d’efficacité chiffrée, pas de capture d’un vrai dossier. TerritoIA n’est pas un accueil. La page ne se copie pas sur le site municipal.

Tenue

Quand l’adresse ou la personne à appeler change, la page change le jour même. STELLARMEET ne conserve pas cette page. Elle est sur l’intranet de la collectivité. Le support n’a pas à la réécrire. L’agent nouveau la lit le premier jour, puis il travaille avec son service. La relecture des pièces, elle, se fait à chaque texte, pas une fois pour toutes à la lecture de la consigne.

La page se relit à voix haute devant un agent du service pilote, une fois, hors slide. Les phrases qui sonnent comme une plaquette se coupent. La DSI note les mots qui ont bloqué. Elle ne garde pas « base de connaissance » si « base de connaissance » est le mot tenu, ni un jargon de fournisseur. L’agent repart avec une seule adresse. Le reste, il le demande à son chef de service. Les habitants n’ont pas de version simplifiée de cette page, parce qu’ils n’ont pas d’usage. En faire une version publique serait ouvrir le guichet qu’on a refusé.

La page interne ne lie pas vers le site public pour « donner le contexte ». Le contexte des agents est leur service. La DSI relit les liens de la page. Un lien vers une démarche habitant se retire : il mélange les deux portes dans le favori de travail.
