La variante se décide dans le règlement, avant les offres, et toutes les pièces le redisent pareil

12 novembre 2026 · TerritoIA, édité par STELLARMEET

Une variante est une offre qui propose une autre façon de répondre au besoin. L’autoriser, l’interdire ou l’encadrer est un choix de l’acheteur, écrit avant la remise des offres, identique dans toutes les pièces que le candidat lit. Le pire dossier est celui qui l’autorise dans le règlement et l’interdit dans l’avis, ou qui se tait. L’acheteur peut demander une vérification de cohérence sur les trois phrases qu’il a écrites. Il corrige les pièces, pas la réalité après coup. Il relit les trois phrases côte à côte.

Décider avant

Le choix dépend du besoin : parfois une solution différente est bienvenue, parfois seule la solution décrite est acceptable pour des raisons techniques que le prescripteur assume. L’acheteur fait écrire cette raison. Il ne coche « variantes interdites » par réflexe de modèle. Un modèle ancien se relit sur ce point précis, parce que les modèles se recopient avec la mauvaise case.

Si les variantes sont encadrées — exigences minimales qu’elles doivent respecter — ces exigences se décrivent. « Variantes libres » sans filet, pour un ouvrage contraint, est un choix lourd. L’acheteur le dit au prescripteur. Les deux relisent le paragraphe.

Au moment des offres

Une offre variante, si elle était interdite, ne se juge pas « quand même » parce qu’elle est séduisante. Une offre de base manquante, si le règlement la rend obligatoire à côté d’une variante, se traite selon ce que le règlement a dit. L’acheteur ouvre le règlement publié, pas son intention initiale. Il le relit avant de rédiger le rapport.

On peut l’aider à formuler le constat (« variante remise alors que le règlement publié les interdit »). Le constat doit être vrai. L’acheteur vérifie sur le PDF publié, qui peut différer du dernier brouillon.

Publication et signature

L’autorité signe le lancement. Les candidats lisent la règle des variantes sur le profil d’acheteur. Ils ne viennent pas la négocier dans l’outil des agents, qui n’est ni le profil, ni un accueil, ni le site municipal.

Le maire ne signe pas une exception orale pour une entreprise. Si une modification de la règle est encore possible, c’est un modificatif du dossier, publié, avant les offres. L’acheteur relit que toutes les pièces en ligne disent la même chose, le jour de la publication.

Trois phrases sur une seule page

L’acheteur imprime ou réunit sur une page les trois phrases : avis, règlement, grille. Il les fait lire par un collègue qui coche « identiques » ou qui souligne l’écart. La page datée entre dans le dossier de lancement. S’il y a écart, la publication attend. Cette page toute simple évite le contentieux le plus évitable du service.

Il relit après correction que la page a été refaite, pas seulement corrigée dans un coin. Les candidats voient la règle sur le profil. L’outil interne n’est pas ce profil et n’est pas un accueil. L’autorité signe le lancement. Une exception orale pour une variante séduisante ne se signe pas du tout.
